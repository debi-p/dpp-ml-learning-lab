System Architecture

The same model can be used from CLI, SDK, REST API, visualizer, and desktop app.

01

Train and Export

Each model saves weights, vocabulary, labels/config, model card, and related artifacts.

02

Register

model_registry/registry.json maps model IDs to artifact paths and supported operations.

03

Serve and Inspect

common_model_api exposes prediction and inspection endpoints for model UIs.

04

Package

Marg packages the Gita RAG model and intent model into a standalone offline macOS app.

Current Models

Run Locally

A quick command map for live demos and local action.

python3 run_all_tests.py

# Gita models: run tests

python3 run_all_tests.py

# Common API
cd /Users/debi.pradhan/Documents/ML/common_model_api
uvicorn app:app --reload --port 8010

# Visualizer UI
cd /Users/debi.pradhan/Documents/ML/model_flow_visualizer
python3 serve_ui.py

# Marg desktop app
cd /Users/debi.pradhan/Documents/ML/03_marg_offline_assistant
python3 run_marg_desktop.py
